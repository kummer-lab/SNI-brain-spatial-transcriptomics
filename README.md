# SNI-brain-spatial-transcriptomics

Analysis code for spatial transcriptomic profiling of mouse brain following spared nerve injury (SNI).

This repository contains preprocessing and downstream analysis scripts used for the associated manuscript.

Repository structure
preprocessing/
    Space Ranger and Seurat preprocessing scripts
    anatomical annotation cleanup

analysis/
    01a_visium_general.Rmd
    01b_visium_regional_marker_dotplot.Rmd
    02_visium_DEG.Rmd
    03_visium_pathway_analysis.Rmd
    04_cross_region_similarity.Rmd
    05_RRHO_transcriptional_programs.Rmd

Analysis workflow

The analysis notebooks are intended to be run in numerical order within the same R session, as some downstream notebooks use objects generated by earlier analyses.

The main downstream analyses include:

general spatial transcriptomics characterization
regional marker analysis
region-wise differential expression analysis
GO/KEGG pathway analysis and semantic clustering
cross-region Spearman and Jaccard similarity analysis
rank-rank hypergeometric overlap (RRHO) analysis


Software

Analyses were performed in R. Required packages are specified in the individual notebooks.
